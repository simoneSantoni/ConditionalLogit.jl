# Validation

ConditionalLogit.jl is checked against published output from SAS and Stata, against R
`survival::clogit(method = "exact")`, and against independent internal oracles.

## SAS

Every number printed in the SAS/STAT documentation for the matched-pairs example
LOGIEX11 is reproduced at SAS's printed precision with the default settings: Model Fit
Statistics, the three global tests, the parameter estimates and the odds ratios (test
`test/test_sas.jl`).

## Stata

The three model fits in the Stata `[R] clogit` manual entry are reproduced to every digit
Stata prints, using `gconv = 1e-16`:

| Example | Data | What is checked |
|:--|:--|:--|
| 1 | `clogitid` (369 obs, up to 2 positive outcomes per group) | coefficients, std. errors, z, CIs, `Number of obs`, `LR chi2`, `Log likelihood`, `Pseudo R2` |
| 2 | `lowbirth2` (56 matched pairs, factor variable `i.race`) | the same, for 7 parameters |
| 4 | `union` (26,200 obs, fixed-effects panel; 2,744 groups dropped, `black` omitted) | the same, plus `Number of obs = 12,035` and the omitted variable |

The weighted McNemar example (example 3, frequency weights on groups) is reproduced on
the [Stata page](@ref stata-fweights).

The script `validation/stata_manual.R` downloads the Stata Press data sets and
`validation/stata_manual.jl` runs the comparison. It is not part of `Pkg.test()`,
because it needs the network (commands below).

With the SAS default `gconv = 1e-8`, 2–4 coefficients per example differ from Stata in
the last of the seven printed digits, because Stata takes one more Newton step (see
[Stata clogit](@ref)).

**Full precision.** `validation/stata_manual.do` reruns the three examples in Stata
(checked with Stata/MP 15). It saves the results at full precision, with Stata's default
convergence settings and with tight ones (`nrtolerance(1e-12) tolerance(1e-14)`).
`stata_manual.jl` then compares them with ConditionalLogit.jl (`gconv = 1e-16`):

| Example | Stata settings | max \|Δβ\| | max \|Δ se\| | \|Δℓ\| | \|Δℓ(0)\| |
|:--|:--|--:|--:|--:|--:|
| `clogitid` | default | 7e-10 | 9e-12 | 0 | 1e-14 |
| `lowbirth2` | default | 3e-11 | 8e-12 | 2e-14 | 7e-15 |
| `union` | default | 9e-11 | 1e-12 | 0 | 6e-12 |
| `clogitid` | tight | 5e-12 | 2e-14 | 0 | 1e-14 |
| `lowbirth2` | tight | 8e-15 | 3e-15 | 2e-14 | 7e-15 |
| `union` | tight | 9e-11 | 1e-12 | 0 | 6e-12 |

The agreement in ℓ(0) confirms that Stata's `e(ll_0)` is the conditional log-likelihood
at β = 0, `nullloglikelihood(m)`.

```bash
Rscript validation/stata_manual.R                    # downloads the data (.dta and .csv)
(cd validation && stata-mp -b do stata_manual.do)    # optional: Stata's full-precision results
julia --project=docs validation/stata_manual.jl
```

## R

R `survival` 3.8-6, `clogit(method = "exact")`:

- **Fixtures** (`test/test_reference.jl`, generated by
  `test/reference/generate_reference.R`): infert; LOGIEX11 with gall + hyper; synthetic
  data with m_k > 1, unequal stratum sizes, uninformative strata, string ids, a
  categorical covariate, an offset, missing values, event = 0, large strata (n = 200,
  m up to 170), and FREQ (checked against R on row-expanded data).
  - With `gconv = 1e-16`, coefficients agree to ≤ 2e-9 absolute (most ≤ 1e-11), and
    log-likelihoods to ≤ 5e-12.
  - At a fixed β, the log-likelihood, score statistic and covariance agree to ≤ 2e-14
    relative.
- **Benchmark data** ([Performance](@ref)): on all seven scenarios (up to 1,000,000 rows),
  coefficients agree with R to ≤ 2e-14, except the fixed-effects panel (7e-9), where R's
  stopping rule ends a little earlier. They agree with Stata to between 4e-12 and 2e-7,
  depending on where Stata's default stopping rule ends.

## statsmodels

statsmodels 0.15.0, `ConditionalLogit`:

- **SAS matched-pairs example:** with `fit(method="newton")` the estimate is
  0.9555114450, the same as ConditionalLogit.jl (`gconv = 1e-16`) to all ten digits, and
  the standard error agrees to 1e-8 relative (statsmodels uses a numerical Hessian).
- **Benchmark data** ([Performance](@ref)): with statsmodels' default BFGS,
  coefficients agree to 1e-5–1e-4. This is the BFGS stopping tolerance, not a difference
  in the likelihood (see [Python statsmodels](@ref)).

## Internal checks

- brute-force subset enumeration on 200 random designs;
- ForwardDiff gradients and Hessians, including at β = 0;
- a 512-bit BigFloat oracle;
- invariance tests (row order, stratum labels, within-stratum shifts, scaling, duplicated strata, uninformative strata) and closed forms for matched pairs (McNemar);
- thread-count invariance (bitwise identical results).
