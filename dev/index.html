ConditionalLogit.jl

Conditional logit models in Julia, estimated by exact conditional maximum likelihood.

Overview

The conditional logit model (conditional logistic regression) is the standard model for data grouped into strata:

  • Matched case–control studies: each matched set is a stratum, and the cases are its events.
  • Fixed-effects (Chamberlain) logit: each panel unit is a stratum, and the unit intercepts are conditioned out of the likelihood.
  • McFadden's choice model: each choice set is a stratum with exactly one chosen alternative.

ConditionalLogit.jl is written so that published results can be reproduced, whichever program produced them. It computes the same exact conditional likelihood as SAS PROC LOGISTIC with a STRATA statement, Stata clogit (and xtlogit, fe) and R survival::clogit, and documents how to map each program's syntax, defaults and output onto it. A sentence such as

We estimated the conditional logit model by maximum likelihood using PROC LOGISTIC in SAS (release 9.3).

needs no options at all: the defaults follow SAS (starting values, Newton–Raphson convergence rule, fit statistics, global tests, odds-ratio tables), and results print in a SAS-like layout. For Stata, R and Python statsmodels, the comparison pages list the few differences in definitions (BIC, weights, uninformative strata) and how to reproduce them.

Features

  • Exact conditional likelihood for any number of events per stratum (no Breslow or Efron approximation), computed with an overflow-free log-space form of the Gail–Lubin–Rubinstein recursion
  • Reproduces SAS, Stata, R and statsmodels: SAS PROC LOGISTIC defaults (start at β = 0, Newton–Raphson with GCONV=1e-8, MAXITER=25) and tables; every printed number of the SAS and Stata manual examples; R survival::clogit(method = "exact") to 1e-9 or better
  • StatsModels formulas and a matrix interface, any Tables.jl source, categorical covariates, FREQ weights, offsets, and multi-column strata keys
  • StatsAPI RegressionModel: coef, stderror, vcov, confint, coeftable, aic, bic, lrtest, predict, …
  • Diagnostics: collinearity within strata (aliased coefficients), complete and quasi-complete separation, non-convergence
  • Multithreaded over strata, with results that are bitwise identical for any number of threads; fits can run concurrently inside Threads.@threads
  • Fast: on one thread, 7–22× faster than R survival::clogit, 13–41× faster than Stata clogit and 144–324× faster than Python statsmodels; 18–53× faster than Stata/MP on 16 cores (see Performance)

Installation

ConditionalLogit.jl is not yet in the General registry. Install it from GitHub:

using Pkg
Pkg.add(url="https://github.com/simoneSantoni/ConditionalLogit.jl")

Or for development:

using Pkg
Pkg.develop(path="/path/to/ConditionalLogit.jl")

Julia 1.10 or later is required.

Choosing an Entry Point

Use CaseCall
Formula and a tableclogit(@formula(y ~ x1 + x2), df; strata = :id)
StatsAPI stylefit(ConditionalLogitModel, @formula(y ~ x), df; strata = :id)
Design matrixclogit(X, y, strata) (no intercept column)
Several columns form the stratum (SAS strata a b;)clogit(f, df; strata = [:hospital, :set])
SAS FREQclogit(f, df; strata = :id, freq = :n)
SAS OFFSET=clogit(f, df; strata = :id, offset = :o)
SAS default response ordering (models Y = 0)clogit(f, df; strata = :id, event = 0)
Stata clogit y x, group(id) / xtlogit y x, feclogit(@formula(y ~ x), df; strata = :id)
R clogit(y ~ x + strata(id))clogit(@formula(y ~ x), df; strata = :id)
statsmodels ConditionalLogit.from_formula("y ~ 0 + x", groups="id", data=df)clogit(@formula(y ~ x), df; strata = :id)
Match Stata or R to every printed digitclogit(f, df; strata = :id, gconv = 1e-16)

See the Tutorial for worked examples, and Comparison with SAS, Stata, R and Python for the details that matter when you compare with published output from those programs.

Performance snapshot

ConditionalLogit.jl compared with R survival::clogit(method = "exact"), Stata clogit and Python statsmodels ConditionalLogit on seven synthetic data sets from 40,000 to 1,000,000 rows. All four programs give the same estimates up to their convergence tolerances.

Each cell is the other program's time divided by ConditionalLogit.jl's time, so a value above 1× means ConditionalLogit.jl finished first:

  • "vs R", "vs Stata, 1 core", "vs Stata/MP, 16 cores", "vs statsmodels": ConditionalLogit.jl on one thread. R and statsmodels are single-threaded.
  • "Julia best" columns: ConditionalLogit.jl at its fastest of 1, 8 or 24 threads.
  • Settings: every program used its default settings on the same data.
