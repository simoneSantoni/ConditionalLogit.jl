Tutorial

This tutorial fits conditional logit models to two classic matched case–control data sets, shows how to read the results, and covers the options that matter when you reproduce published SAS output.

using ConditionalLogit, CSV, DataFrames, StatsModels

Matched pairs: LOGIEX11

The SAS/STAT example LOGIEX11 has 63 matched pairs. s is the pair, y is 1 for the case, and gall and hyper are indicators for gall-bladder disease and hypertension.

la = CSV.read(pkgdir(ConditionalLogit, "test", "reference", "la.csv"), DataFrame)
m1 = clogit(@formula(y ~ gall + hyper), la; strata = :s)

Matching SAS class coding

SAS PROC LOGISTIC codes CLASS variables with PARAM=EFFECT and the last level as reference, while StatsModels uses dummy coding with the first level as base. Pass contrasts to reproduce the SAS parameter table:

clogit(@formula(y ~ g), df; strata = :id,
       contrasts = Dict(:g => EffectsCoding(base = "c")))   # SAS PARAM=EFFECT, last level "c"
clogit(@formula(y ~ g), df; strata = :id,
       contrasts = Dict(:g => DummyCoding(base = "c")))     # SAS PARAM=REF

oddsratios reports level-versus-reference odds ratios computed from the contrast matrix, so they match SAS under either coding.

Response ordering

By default SAS models the probability of the lower ordered response value, which is Y = 0 for a 0/1 outcome, unless the code says event='1' or descending. Use event = 0 to reproduce such output. Every coefficient changes sign, and the fit statistics and tests are unchanged:

m4 = clogit(@formula(y ~ gall + hyper), la; strata = :s, event = 0)
coef(m4) ≈ -coef(m1), deviance(m4) ≈ deviance(m1)
(true, true)

Matrix interface

X = Matrix(la[:, [:gall, :hyper]])
m5 = clogit(X, la.y, la.s)
coef(m5) ≈ coef(m1)
true

Convergence and accuracy

As in SAS, the fit stops when the relative gradient criterion falls below gconv = 1e-8 and reports that iterate without taking one more step. The estimates therefore agree with the exact optimum to about six significant digits, which is all SAS prints. For full accuracy, tighten the criterion:

m6 = clogit(@formula(y ~ gall + hyper), la; strata = :s, gconv = 1e-16)
coef(m6) .- coef(m1)
2-element Vector{Float64}:
 5.696364904217432e-7
 1.3333315912467114e-7

Non-convergence and separation give a warning and converged(m) == false, as SAS does. Pass strict = true to throw a ConvergenceError instead.

Predictions

fitted(m) gives the within-stratum probability that each observation is an event. predict(m, newdata; strata) gives choice probabilities for new choice sets (one event per stratum), and type = :linpred gives x'β̂:

predict(m1, first(la, 4); strata = first(la.s, 4))

Threads

Strata are processed by several tasks (ntasks, default Threads.nthreads()), and the results are bitwise identical for any number of threads. Start Julia with julia -t auto to use them. Fits can also run concurrently, for example a bootstrap inside Threads.@threads.
