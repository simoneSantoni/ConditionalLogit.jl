Development

Tests

julia --project -e 'using Pkg; Pkg.test()'                      # full test suite (no R needed)
julia --project -e 'using Pkg; Pkg.test(julia_args=`-t 4`)'     # the same, multithreaded

The R reference fixtures in test/reference/ are produced only by test/reference/generate_reference.R, which needs R with the survival and jsonlite packages:

Rscript test/reference/generate_reference.R

Benchmarks

julia --project=benchmark -t 8 benchmark/bench.jl [choice mixed unequal bigstrata offset stringids]
julia --project=benchmark benchmark/run_threads.jl mixed          # thread sweep, checks bitwise-identical results

The benchmark environment uses [sources], which needs Julia 1.11 or later. On Julia 1.10, run julia --project=benchmark -e 'using Pkg; Pkg.develop(path = ".")' once first.

Documentation

julia --project=docs -e 'using Pkg; Pkg.instantiate()'
julia --project=docs docs/make.jl

The site is built into docs/build/. On every push to main, the Documentation GitHub Actions workflow builds it and deploys it to the gh-pages branch.
