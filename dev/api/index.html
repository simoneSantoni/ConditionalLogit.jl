Module

ConditionalLogit — Module
ConditionalLogit

Conditional (fixed-effects / matched-set) logistic regression by exact conditional maximum likelihood, written to reproduce SAS PROC LOGISTIC with a STRATA statement (and survival::clogit(method = "exact") in R, Stata clogit).

Main entry points: clogit / fit(ConditionalLogitModel, ...), the StatsAPI accessors (coef, stderror, vcov, loglikelihood, aic, bic, ...), and the SAS-table accessors fitstatistics, globaltests, oddsratios, stratasummary.

Fitting

ConditionalLogit.clogit — Function
clogit(formula, data; strata, kwargs...)
clogit(X, y, strata; kwargs...)

Fit a conditional logit model (conditional logistic regression for matched sets). This is the same as fit(ConditionalLogitModel, ...); see its docstrings for the keywords.

m = clogit(@formula(case ~ spontaneous + induced), infert; strata = :stratum)
source
StatsAPI.fit — Method
fit(ConditionalLogitModel, formula, data; strata, kwargs...)
clogit(formula, data; strata, kwargs...)

Fit a conditional logit model by exact conditional maximum likelihood, the model fitted by SAS PROC LOGISTIC with a STRATA statement.

  • formula: a StatsModels @formula(y ~ x1 + x2 + ...). There is no intercept: it is conditioned out with the strata, so y ~ x and y ~ 0 + x are the same model and y ~ 1 + x is an error. Categorical covariates get full-rank (k−1) contrasts.
  • data: any Tables.jl table.
  • strata (required): the column name(s) identifying the strata (matched sets), as a Symbol, a String, or a vector of Symbols or Strings (combined key, like SAS strata a b;). It may also be a vector of stratum values (one per row of data). A vector of Symbols is always read as column names; a vector of Strings is read as column names when every element is a column name and its length differs from the number of rows. strata may also be passed positionally: fit(ConditionalLogitModel, formula, data, strata).

Keywords:

  • event: the response level that is the event. The default is true / 1 for Bool or 0/1 responses; any other two-level response requires it. SAS without EVENT= or DESCENDING models the lower value (0); use event = 0 to reproduce such output.
  • freq: FREQ column name or vector. Each row counts as freq identical observations. Non-integers are truncated; rows with freq < 1 are dropped. weights = fweights(v) is accepted as an alias; other weights are rejected.
  • offset: offset column name or vector (SAS OFFSET=).
  • contrasts: a Dict of StatsModels contrasts (e.g. EffectsCoding(base = last) to reproduce SAS PARAM=EFFECT).
  • strata_missing = false: treat a missing stratum value as a valid stratum (SAS STRATA ... / MISSING). By default such rows are dropped.
  • Fitting options: maxiter, gconv, fconv, absfconv, xconv, maxstephalving, singular, dropcollinear, ntasks, sc_n, start, strict, verbose; see FitOptions.

Only the columns named in the formula, strata, freq and offset are read from data. Rows with a missing value in any of them are dropped (listwise deletion).

source
StatsAPI.fit — Method
fit(ConditionalLogitModel, X, y, strata; kwargs...)
clogit(X, y, strata; kwargs...)

Fit a conditional logit model from a covariate matrix X (n×p, no intercept column), a binary response y and a vector of stratum identifiers strata (any hashable values). Rows with missing in X, y, strata, freq or offset are dropped.

strata may also be given as a keyword: clogit(X, y; strata = s).

Keywords: event, freq, weights (only fweights), offset, strata_missing, coefnames, responsename, plus the fitting options in FitOptions. See clogit.

ConditionalLogit.FitOptions — Type
FitOptions

Options for the Newton–Raphson fit. The defaults are the SAS PROC LOGISTIC defaults for a conditional (STRATA) analysis. Every field can be passed as a keyword to clogit / fit.

  • maxiter = 25: maximum number of Newton–Raphson iterations (SAS MAXITER=).
  • gconv = 1e-8: relative gradient criterion g'I⁻¹g / (|ℓ| + 1e-6) (SAS GCONV=).
  • fconv, absfconv, xconv (all 0.0, which means off): the SAS FCONV=, ABSFCONV= and XCONV= criteria. As SAS does for STRATA models, an exactly zero change in the log likelihood or in the parameters between iterations also stops the iterations.
  • maxstephalving = 50: maximum number of step-halvings when a Newton step decreases ℓ. Halving also stops once the step is negligible relative to β.
  • singular = 1e7 * eps() ≈ 2.2e-9: tolerance of the in-order collinearity sweep. The default is the SAS SINGULAR= default. SAS tests the sweep pivot of the Hessian; this package tests 1 − R² of each covariate on the earlier ones in the within-stratum centred (FREQ-weighted) Gram matrix. Both have the same null space, but borderline cases can be decided differently.
  • dropcollinear = true: set aliased coefficients to 0 (SAS behaviour); false throws.
  • ntasks = Threads.nthreads(): number of tasks for the per-stratum work (≥ 1). The results are bitwise identical for any value. Fits may themselves run concurrently (e.g. inside Threads.@threads or Threads.@spawn).
  • sc_n = :informative: which n enters SC/BIC = -2LogL + p·log(n). :informative counts observations (sum of FREQ) in informative strata, and :all counts every observation used. They differ only when there are uninformative strata.
  • start = nothing: starting values (default 0, as in SAS). They must be finite. If ℓ(start) < ℓ(0), the start is discarded with a warning and the fit starts from 0.
  • strict = false: throw a ConvergenceError instead of warning when the fit did not converge or the data are separated.
  • verbose = false: print the iteration history while fitting.

SAS-style Results

ConditionalLogit.fitstatistics — Function
fitstatistics(m) -> FitStatistics

SAS "Model Fit Statistics" for a conditional analysis:

  • -2 Log L = −2ℓ. "Without Covariates" is −2ℓ(0) = 2Σk log C(nk, m_k) when there is no offset.
  • AIC = −2 Log L + 2p
  • SC = −2 Log L + p·log(n), with n = nobs(m), the number of observations (sum of FREQ), not the number of strata. This was checked against the SAS LOGIEX11 output. By default (sc_n = :informative) n counts only observations in informative strata; whether SAS also counts uninformative strata is unverified (sc_n = :all does). The text display prints the n used whenever it differs from the observations used.

Here p = dof(m); "Without Covariates" has p = 0. aic(m) and bic(m) return the "With Covariates" AIC and SC.

source
ConditionalLogit.globaltests — Function
globaltests(m) -> GlobalTests

The likelihood ratio, score and Wald tests of the global null hypothesis β = 0, each with df = dof(m) (non-aliased parameters), as in SAS:

  • Likelihood Ratio = 2(ℓ(β̂) − ℓ(0))
  • Score = U(0)' I(0)⁻¹ U(0), evaluated at β = 0 (with the offset, if any)
  • Wald = β̂' I(β̂) β̂ = β̂' V⁻¹ β̂
source
ConditionalLogit.oddsratios — Function
oddsratios(m; level = 0.95) -> OddsRatioTable

Odds ratio estimates with Wald confidence limits (SAS CLODDS=WALD, the default table).

  • A continuous main effect gets exp(β), for a one-unit increase.
  • A categorical main effect gets one row per non-reference level, labelled "var level vs base". The estimate is the level-versus-reference contrast computed from the term's contrast matrix, so it is right under effect coding too (SAS PARAM=EFFECT), where exp(β) is not an odds ratio.
  • Terms that appear in interactions are omitted, as in SAS.
  • Models fitted from a matrix get exp(β) for each non-aliased coefficient.
source
ConditionalLogit.oddsratio — Function
oddsratio(m, c::AbstractVector; level = 0.95) -> (estimate, lower, upper)

Odds ratio exp(c'β̂) for a general contrast c (length p), with Wald limits exp(c'β̂ ± z·√(c'Vc)). Aliased coefficients must have zero weight.

source
ConditionalLogit.stratasummary — Function
stratasummary(m) -> StrataSummary

The SAS "Strata Summary": strata grouped by response pattern (events, non-events), uninformative patterns included. It is a Tables.jl table (DataFrame(stratasummary(m))) with columns pattern, events, nonevents, nstrata, frequency, informative.

ConditionalLogit.StrataSummary — Type
StrataSummary

Counts of strata by response pattern (SAS "Strata Summary"). Strata in which every observation is an event, or none is, are uninformative. Their conditional likelihood is identically 1, so they are reported here but not used in the analysis.

It is a Tables.jl table with one row per response pattern and columns pattern, events, nonevents, nstrata, frequency and informative.

source
ConditionalLogit.StrataPattern — Type
StrataPattern

One row of the SAS "Strata Summary" table: strata with nevents events and nnonevents non-events (both counted with FREQ).

source
ConditionalLogit.ResultTable — Type
ResultTable

Supertype of the small result tables (strata summary, fit statistics, global tests, odds ratios). Each implements the Tables.jl column interface, so DataFrame(t) works.

StatsAPI Methods

The usual StatsAPI accessors (coef, coefnames, stderror, aic, aicc, bic, deviance, nulldeviance, responsename, weights, islinear) also work on a ConditionalLogitModel. The methods below have behaviour specific to the conditional logit model.

StatsAPI.vcov — Method
vcov(m)

Inverse information matrix at β̂, the SAS covariance of the estimates (COVB). Rows and columns of aliased coefficients are NaN.

source
StatsAPI.informationmatrix — Method
informationmatrix(m; expected = true)

Information matrix at β̂: minus the Hessian of the conditional log-likelihood, which is Var[x_S] summed over strata. It does not depend on the response, so the observed and expected information are the same. Aliased rows and columns are 0.

source
StatsAPI.score — Method
score(m)

Gradient of the conditional log-likelihood at β̂ (≈ 0 at convergence). The score test of β = 0 is in globaltests.

source
StatsAPI.loglikelihood — Method
loglikelihood(m)

Exact conditional log-likelihood at β̂. Summed over informative strata, with FREQ weighting. -2loglikelihood(m) is SAS "-2 Log L, With Covariates".

source
StatsAPI.nullloglikelihood — Method
nullloglikelihood(m)

Conditional log-likelihood at β = 0 (with the offset, if any). Without an offset it is -Σ_k log C(n_k, m_k). -2nullloglikelihood(m) is SAS "-2 Log L, Without Covariates".

source
StatsAPI.nobs — Method
nobs(m)

The number of observations used, which is the n in SC/BIC. It is the sum of FREQ over the observations in informative strata (sc_n = :informative, the default), or over all observations used (sc_n = :all). The two differ only if there are uninformative strata.

source
StatsAPI.dof — Method
dof(m)

Number of estimated (non-aliased) parameters. There is no intercept and no dispersion parameter.

source
StatsAPI.dof_residual — Method
dof_residual(m)

nobs(m) - dof(m). Defined so that StatsModels.lrtest works; the likelihood ratio test itself uses only the deviances and dof.

source
StatsAPI.confint — Method
confint(m; level = 0.95)

Wald confidence limits β̂ ± z·SE (SAS CLPARM=WALD).

source
StatsAPI.coeftable — Method
coeftable(m; level = 0.95)

Standard StatsBase.CoefTable with estimate, standard error, z, p-value and Wald confidence limits. The SAS "Wald Chi-Square" is z², with the same p-value.

source
StatsAPI.modelmatrix — Method
modelmatrix(m)

The covariate matrix of the observations used, in data order.

source
StatsAPI.response — Method
response(m)

The event indicator (true = event) of the observations used, in data order.

source
StatsAPI.fitted — Method
fitted(m)

Within-stratum conditional probability that each observation is an event, given its stratum's number of events: πi = P(i ∈ S). It is the softmax for 1:M matched sets (mk = 1), and Σi fi πi = mk within each stratum. Observations in uninformative strata get 1 (all events) or 0 (no events).

It is computed on the first call and cached (a fit does not pay for it). The cost is O(Σk nk mk) time and O(rowsk · mk) memory per stratum, where nk counts FREQ.

source
StatsAPI.predict — Method
predict(m)
predict(m, newdata; strata, offset = nothing, type = :prob)        # formula models
predict(m, Xnew; strata, offset = nothing, type = :prob)           # matrix models

Without new data, predict(m) == fitted(m).

With new data:

  • type = :linpred gives the linear predictor x'β̂ (+ offset). It has no intercept, so it is identified only up to a constant within each stratum.
  • type = :prob gives the within-stratum choice probabilities exp(ηi) / Σ{j ∈ k} exp(η_j), the probability that row i is the event of its stratum (McFadden's conditional logit for new choice sets: one event per stratum).

strata is a column name (or names) of newdata, or a vector of stratum values. Rows with missing covariates, strata or offset get missing.

Residuals are not defined for this model (residuals gives a MethodError).

source
StatsModels.isnested — Method
StatsModels.isnested(m1, m2; atol = 0)

true if m1 is nested in m2: both were fitted to the same observations (response, strata, FREQ and offset), and every non-aliased covariate of m1 lies, within strata, in the span of the covariates of m2. Used by StatsModels.lrtest.
