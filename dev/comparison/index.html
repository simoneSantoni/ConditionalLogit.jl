Comparison with SAS, Stata, R and Python

ConditionalLogit.jl, SAS PROC LOGISTIC with a STRATA statement, Stata clogit, R survival::clogit and Python statsmodels ConditionalLogit all maximise the same exact conditional likelihood

\[L(\beta) = \prod_k \frac{\exp\left(\sum_{i \in \text{events}_k} x_i'\beta\right)}{\sum_{S \subset \text{stratum } k,\ |S| = m_k} \exp\left(\sum_{j \in S} x_j'\beta\right)},\]

so, fully converged, they give the same estimates, standard errors and log-likelihood. They differ in syntax, defaults, which statistics they print, and how they treat weights, uninformative strata and collinear covariates. This page summarises the differences. The pages for SAS, Stata, R and Python show how to reproduce each program's output, and Performance compares speed.

Which numbers agree

When all five programs are fully converged on the same data (statsmodels with method="newton"):

  • Identical: coefficients, standard errors, z (or Wald χ² = z²), p-values, Wald confidence intervals, odds ratios, log-likelihood, ℓ(0), the likelihood-ratio statistic, AIC.
  • Identical where printed: score and Wald global tests (SAS, R and ConditionalLogit.jl).
  • Close: statsmodels standard errors, which come from a numerical Hessian (about 1e-8 relative).
  • Different by definition:
    • BIC: R uses the number of events as n, SAS and Stata the number of observations. Stata excludes observations in uninformative strata; for SAS this is unverified (see SAS PROC LOGISTIC).
    • The number of observations reported: R counts uninformative strata; Stata and statsmodels do not.
    • Signs: SAS without EVENT='1' or DESCENDING models Y = 0, which negates every coefficient.
  • Different by stopping rule: each program stops at a different point, so the last printed digit can differ. ConditionalLogit.jl's default reproduces SAS. With gconv = 1e-16 it reproduces every digit that Stata and R print (see Validation). statsmodels' default BFGS stops much earlier (about the 5th significant digit), so use method="newton" there.

Weights are not interchangeable

The programs mean different things by frequency weights:

  • SAS FREQ and freq = here: a row with weight 3 is three identical observations in the same stratum. The stratum grows, and so does its number of events.
  • Stata fweight: a group with weight 3 is three identical groups. Weights must be constant within each group.
  • R clogit(method = "exact"): weights are ignored, with a warning.
  • statsmodels: no weights.

To reproduce a Stata fweight analysis, replicate the groups (see Frequency weights). To reproduce SAS FREQ in R, expand the rows.
